PaySphere processes digital payments and seeks to understand transaction behavior and unusual activity patterns using operational data. This project delivers an end-to-end analytical workflow spanning exploratory data analysis, feature engineering, predictive anomaly screening, an interactive financial Excel workbook, and an executive pitch deck.
